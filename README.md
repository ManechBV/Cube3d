# Description
Developed by Id Software, led by the world-renowned John Carmack and John Romero,
and published in 1992 by Apogee Software, Wolfenstein 3D is the first true “First Per-
son Shooter” in the history of video games.

The goal of the project is to recreate a basic version of Wolfenstein raycasting engine
in C.

# Instructions
First clone the minilibx to the root: 
```
git clone https://github.com/42paris/minilibx-linux.git
```
Then compile the project: 
```
make
```
Finally, you can run CUBE3D by giving it a .cub map file:
```
./cube3d maps/map1.cub
```

You can find more maps in the maps folder !
